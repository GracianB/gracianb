## Deploy GitHub Pages

1. Crea el repo **`GracianB/GracianB`** (o el nombre que uses).
2. Sube **solo** el contenido de este pack a la **raíz** (sin carpeta extra).
3. Settings → Pages → branch `main` → `/ (root)`.
4. Live: **https://gracianb.github.io/GracianB/**

> No subas copias con `(1)`, `(2)` en el nombre. Un archivo = un nombre.
